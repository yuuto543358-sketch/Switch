# SWITCH

**One switch. Countless consequences.**

スイッチを押すだけで進む、ミステリー／SFアドベンチャーゲームです。
ブラウザ（Safari・Chrome など）で動きます。スマホでもパソコンでも遊べます。

現在あそべるのは **CHAPTER 01「FIRST SWITCH」** から **CHAPTER 05「THE FACTORY」** までの5章です（全7章を順番に制作中）。

---

## あそびかた

1. タイトル画面のスイッチを押す
2. 「はじめから」を押す
3. 画面の中のスイッチ（照明・テレビのリモコン・インターホン）を押す
4. 文字が出たら、画面のどこかを押すと次へ進む

- スマホの縦画面では、画面を指でなぞると部屋を見回せます
- 右上の「≡」から、設定（音量・文字の速さ）とセーブができます
- 章と章のあいだに区切りの画面はなく、物語はそのまま続きます。どのエンドになったかは、最後にだけ表示されます
- 進み具合は自動で保存され、タイトルの「つづきから」で再開できます
- 一度クリアした章と、その次の章は、タイトルの「チャプター」から選んで始められます

## インターネットに公開する方法（GitHub Pages）

1. GitHub でこのリポジトリのページを開く
2. 上の **Settings**（設定）を押す
3. 左のメニューから **Pages** を押す
4. 「Branch」でゲームが入っているブランチを選び、**Save** を押す
5. 1〜2分待つと、ページの上に公開アドレス（URL）が表示される

そのアドレスをスマホで開き、ブラウザの「ホーム画面に追加」を選ぶと、
アプリのようにアイコンから起動できます。

## 自分のパソコンで試す方法

`index.html` をダブルクリックしてブラウザで開くだけです。

## 画像・音を本物の素材に差し替える

今の背景はプログラムで描いた仮の絵、音はその場で合成した仮の音です。
あとから実写の写真や録音に入れ替えられる作りになっています。

- **背景**：同じ構図の写真（横1920×縦1080）を `assets/bg/` に入れ、
  `js/assets.js` の `ch01_room` などのファイル名を書き換える。
  背景は「照明がついた状態」の1枚だけでOK。暗さやテレビの光はゲームが自動で重ねます。
- **音**：音声ファイルを `assets/audio/` に入れ、`js/assets.js` の `SW.AUDIO_FILES` に
  `switch_on: 'assets/audio/switch_on.mp3'` のように1行足す。
